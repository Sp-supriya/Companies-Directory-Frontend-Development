🏢 Companies Directory – Frontend Application

A responsive React + Tailwind CSS web application that displays a searchable, filterable, and sortable list of companies.
The project demonstrates frontend integration skills, state management, and API consumption using mock data.

🚀 Features

Display a list of companies in a clean card or table layout

Filter by name, industry, and location

Search functionality with instant results

Sorting options (e.g., by company name)

Pagination for better data browsing

Responsive design (works on desktop and mobile)

Smooth loading and error handling states

🧠 Tech Stack

Frontend: React.js (Vite)

Styling: Tailwind CSS

State Management: React Hooks / Context API

Mock API: JSON file or JSON Server (optional backend)

💡 Uses

This project demonstrates:

Building modern React applications with real-world UI patterns

Handling API data and state management

Implementing filters, search, and sorting logic

Structuring and deploying a frontend app effectively


🖥️ Running the Project Locally

Clone the repository

git clone https://github.com/Sp-supriya
Sp-supriya/companies-directory-frontend.git

cd companies-directory-frontend

Install dependencies

npm install

Start the development server

npm run dev

Open the app in your browser at

http://localhost:5173

🗄️ Backend (Optional)

You can either use a simple mock JSON file included in the project or set up a basic Node.js + Express + MongoDB backend to serve real data.
However, the main focus of this assignment is on frontend implementation and API integration.

🌐 Deployment

The project can be easily deployed to platforms like Vercel, Netlify, or Render.
Simply connect your GitHub repository, build, and deploy.
